# Java 高频陷阱

## 对象比较
- `==` / `!=` 比较对象引用地址，字符串和包装类应使用 `.equals()`

## 整数运算
- 整数除法截断小数（`5 / 2 == 2`），需浮点结果时至少一个操作数强转
- `int` 溢出不会报错，大数运算注意 `long`
- 负数取模：`-7 % 3 == -1`，与其他语言不同

## 集合与数组
- `Arrays.asList()` 返回固定大小 List，不能 add/remove
- 遍历中修改集合抛 ConcurrentModificationException
- 泛型擦除导致类型安全丢失

## 字符串
- `substring()` 第二参数 exclusive（不含该位置）
- `split()` 参数是正则，`.` `|` 等需转义

## 递归
- 递归修改传入的集合/数组会产生跨调用副作用
