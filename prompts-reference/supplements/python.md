# Python 高频陷阱

## 比较与身份
- `is` 比较对象身份（内存地址），`==` 比较值；数字和字符串的 `is` 行为不可预测
- `None` 判断应使用 `is None` / `is not None`，不用 `==`

## 迭代与生成器
- 生成器/迭代器只能消费一次，第二次遍历得到空序列
- `for` 循环中修改正在迭代的列表/字典会跳过元素或抛 RuntimeError

## 作用域与闭包
- 循环内创建的 lambda/闭包捕获的是变量引用而非当前值（late binding）
- 函数内赋值会使变量变为局部变量，即使外层有同名全局变量

## 数值与类型
- 浮点精度：`0.1 + 0.2 != 0.3`，金融计算应用 Decimal
- `//` 是整除（向下取整），`/` 始终返回 float
- 负数取模：`-7 % 3 == 2`（结果符号跟除数），与其他语言不同
